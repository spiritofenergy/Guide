# План: Добавить дату публикации под "Оплата картой" в ParallaxScreen

## Цель
Отобразить дату публикации поста под секцией "Оплата картой" в `MainContent.kt`.

## Файлы для изменения
- `app/src/main/java/com/kodex/guide/presentation/details/parallaxScreen/MainContent.kt`

## Изменения

### 1. Добавить импорты в `MainContent.kt`
```kotlin
import java.time.Instant
import java.time.ZoneId
import java.time.format.DateTimeFormatter
```

### 2. Добавить форматирование даты
После `val telephone = navObject.telephone` добавить:
```kotlin
val publicationDate = remember(navObject.timestamp) {
    val date = Instant.ofEpochMilli(navObject.timestamp)
        .atZone(ZoneId.systemDefault())
    DateTimeFormatter.ofPattern("dd.MM.yyyy", java.util.Locale.getDefault())
        .format(date)
}
```

### 3. Добавить отображение даты под "Оплата картой"
В секции "Услуги", после блока `if (navObject.payment)`, добавить:
```kotlin
if (navObject.payment) {
    ServiceInfoRow(
        icon = Icons.Default.CreditCard,
        title = "Оплата картой",
        subtitle = "Принимаем банковские карты",
        color = Color(0xFF3B82F6)
    )
    Spacer(modifier = Modifier.height(4.dp))
    Text(
        text = "Опубликовано: $publicationDate",
        fontSize = 13.sp,
        color = TextGray,
        fontWeight = FontWeight.Medium
    )
    Spacer(modifier = Modifier.height(4.dp))
}
```

## Верификация
- Собрать проект: `./gradlew assembleDebug`
- Проверить, что дата отображается под "Оплата картой" в формате `dd.MM.yyyy`
- Убедиться, что если "Оплата картой" не отображается (payment=false), дата тоже не показывается
